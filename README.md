# Wishtaa Sheets

Each Google Sheet is a node on a mind-map canvas; links mean "output of this sheet
feeds the input of that sheet". Built for accounting reconciliation pipelines.

Stack: Next.js (App Router) + TypeScript + Tailwind, React Flow, Supabase.

```
npm install
npm run dev   # http://localhost:3100
```

Copy `.env.example` to `.env.local` and fill in the Supabase URL and anon key.
